## 2. Android Permissions Manifest

The application requests only essential network connectivity permissions required for Capacitor's network detection and optional backend connection. It requires **zero high-risk permissions** (no location, no camera, no contacts, no microphone, no external storage reading):

```xml
<!-- android/app/src/main/AndroidManifest.xml -->
<manifest xmlns:android="http://schemas.android.com/apk/res/android">
    <uses-permission android:name="android.permission.INTERNET" />
    <uses-permission android:name="android.permission.ACCESS_NETWORK_STATE" />
</manifest>
```

## 6. Build Modes & Artifact Specifications

### Offline Standalone Debug APK (`build_mode: offline`, `build_type: debug`)
* **Gradle Task:** `./gradlew assembleDebug`
* **Output Path:** `android/app/build/outputs/apk/debug/app-debug.apk`
* **Artifact Upload Name:** `MathSphere-AI-Android-Debug-APK`
* **Network Behavior:** No server calls made; launches directly into embedded solvers.
* **Server Dependency:** Completely independent. Can be installed and tested on any Android device in airplane mode.

### Online Connected Debug APK (`build_mode: online`, `build_type: debug`)
* **Gradle Task:** `./gradlew assembleDebug`
* **Output Path:** `android/app/build/outputs/apk/debug/app-debug.apk`
* **Validation:** Workflow ensures `vars.CAPACITOR_SERVER_URL` is set to a valid public HTTPS endpoint.
* **Network Behavior:** Loads remote web platform; automatically queues mutations to IndexedDB if offline.
